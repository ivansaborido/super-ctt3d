# Super CTT 3D

Juego de plataformas 3D: lleva el envío desde tu comunidad hasta la central de Coslada.
Son 9 archivos sueltos, sin carpetas. Súbelos todos a la raíz del repositorio de GitHub.

- `index.html`: el juego completo (incluye el motor 3D three.js, licencia MIT, y las fuentes Barlow y Lilita One, licencia OFL).
- `manifest.webmanifest`: nombre e icono de la app.
- `sw.js`: permite jugar sin conexión. Si subes una versión nueva, cambia el número de `VERSION` (v3, v4…).
- `icon-*.png`, `apple-touch-icon.png`, `favicon.png`: iconos.

Dirección del juego: `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`
